Inspector

An investigation and negotiation game. Download the offline playtest for Linux.

Download for Linux

One ZIP · 187.6 MB · x86_64 · Full-quality assets

Python, the game runtime, and the local backend are included. No installation, API key, or backend setup is required.

Extract. Launch. Play.

  1. Download the ZIP on the Linux laptop.
  2. Extract the entire Inspector folder to a writable location.
  3. Open the folder and run Inspector. Keep the other folders beside it.

If Linux blocks execution, open Properties → Permissions and allow the Inspector file to run as a program. First launch imports the game resources and may take a little longer.

What you’re downloading

This is the current offline prototype, not a finished release. Dialogue uses labelled scripted fixtures, not live AI. Characters are static and CCTV uses authored text frames. Audio and some visual feedback are not complete.

Two winning routes, two failure outcomes, investigation, police operations, and save/recovery are included. No models or textures have been reduced for this download.

Linux x86_64 only, with glibc 2.31+ and a compatible OpenGL graphics driver. Not a Windows EXE, Android APK, ARM build, or game that runs inside your phone’s browser.

Controls and verification

WASD to move, mouse to look, E to interact, Esc to pause. Use the desk/chair to open the PC. Dialogue cards prepare a message; press Kirim pesan to send.

The bundled launcher, all four outcomes, and save/restart were exercised in a clean Debian container with no installed Python or Godot and no Internet access. The extracted final ZIP was cold-launched too. Your laptop’s graphics and performance still need a playtest; the full rendered outcome suite timed out on the build machine.
