Extract. Launch. Play.

  1. Download the ZIP on the Linux laptop.
  2. Extract the entire Inspector folder to a writable location.
  3. Open the folder and run Inspector. Keep the other folders beside it.

If Linux blocks execution, open Properties → Permissions and allow the Inspector file to run as a program. First launch imports the game resources and may take a little longer.

What you’re downloading

This is the current offline prototype, not a finished release. Dialogue uses scripted fixtures, not live AI. Characters are static and CCTV uses authored text frames. Music and interaction sounds include their required WAV import settings (corrected in r2); character animation and other presentation remain prototype-quality.

This update adds physical-briefing onboarding, a 30-minute case deadline, refreshed PC applications and persistent multi-tab notes. Two winning routes, two failure outcomes, investigation, police operations, and save/recovery are included. No models or textures were reduced during packaging.

Linux x86_64 only, with glibc 2.31+ and a compatible OpenGL graphics driver. Not a Windows EXE, Android APK, ARM build, or game that runs inside your phone’s browser.

Controls and verification

WASD to move, mouse to look, E to interact. First read and close the physical victim briefing on the desk, then answer the incoming call. Esc leaves the PC immediately; while walking it opens Settings. Dialogue cards prepare a message; press Kirim pesan to send.
